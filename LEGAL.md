## 1. Educational & Scientific Research Purpose

Sovereign Fortress is an independent, non-commercial, open reference implementation developed **exclusively for educational, academic, and telecommunications research purposes**. 

The primary objectives of this project are:
1. To study modern transport-layer protocols, including **QUIC (RFC 9000)**, **HTTP/3**, **TLS 1.3**, and **WireGuard kernel integration**.
2. To measure network latency, throughput, and packet-loss resilience across lossy and high-latency wireless channels.
3. To evaluate zero-trust ephemeral memory architectures (RAM-only runtime environments utilizing volatile `tmpfs`).
4. To test automated public key infrastructure (PKI) integration with ACME (RFC 8555) and Let's Encrypt.
